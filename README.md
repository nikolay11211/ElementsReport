# Ведомость элементов

Плагин для Autodesk Revit. Внешняя команда: собирает стены модели и показывает список с площадями и суммой.

Интерфейс на WPF, паттерн MVVM.

## Сборка и отладка

Откройте `ElementsReport.sln` в любой среде, которая собирает проекты под .NET Framework.

Версия Revit выбирается конфигурацией сборки: `Debug R21` собирает под Revit 2021, `Debug R23` под 2023 и так далее, всего поддержаны 2021, 2022, 2023 и 2024. Сборки Revit API лежат в папке `RevitApi` внутри проекта, нужная версия подключается автоматически по выбранной конфигурации. Установленный Revit для сборки поэтому не нужен, он нужен только чтобы запустить результат.

Если выбрать конфигурацию без версии, сборка остановится с понятным сообщением, а не с простынёй ошибок компилятора.

Сборка сама разворачивает плагин в `%AppData%\Autodesk\Revit\Addins\<версия>`, отдельных действий не требуется. Revit во время сборки должен быть закрыт, иначе файлы заняты.

Для запуска в `Properties/launchSettings.json` лежат профили с именами «Revit 2021» и далее по версиям. Выберите профиль той же версии, что и конфигурация, и нажмите F5: в Visual Studio и Rider Revit поднимется с подключённым отладчиком, точки останова срабатывают сразу. Если Revit установлен не в стандартную папку, поправьте путь в нужном профиле. Если среда профили не понимает, запустите Revit сами и подключитесь отладчиком к его процессу.

Проект собирается под .NET Framework 4.8: `record` и `init` там не компилируются, используйте обычные классы.

## Структура

| Путь | Назначение |
|---|---|
| `ElementsReport.sln` | Решение с единственным проектом плагина |
| `ElementsReport.csproj` | Файл проекта: выбор версии Revit по конфигурации, пакеты и развёртывание после сборки |
| `ElementsReport.addin` | Манифест плагина для Revit, кладётся рядом со сборкой автоматически |
| `RevitApi/` | Сборки Revit API по версиям, подключаются относительным путём |
| `.gitignore` | Что не должно попадать в репозиторий |
| `Command.cs` | Точка входа: собирает модель представления, показывает окно |
| `MainWindow.xaml` | Главное окно |
| `MainWindow.xaml.cs` | Code-behind окна: только конструктор, логики нет |
| `Abstractions/ObservableBase.cs` | База observable-типов. Уведомления для auto-property внедряет Fody, вызывать `OnPropertyChanged` руками нужно только для вычисляемых свойств |
| `FodyWeavers.xml` | Настройка weaver-а PropertyChanged |
| `Abstractions/IElementsReportService.cs` | Контракт построения ведомости |
| `Commands/RelayCommand.cs` | Синхронная команда с обработчиком ошибок |
| `Converters/StringToVisibilityConverter.cs` | Видимость по непустой строке |
| `Helpers/UnitHelper.cs` | Перевод внутренних единиц Revit в квадратные метры |
| `Lang/` | Ресурсы локализации, нейтральная культура плюс `ru` и `en` |
| `Models/ElementRow.cs` | Строка ведомости |
| `Models/ElementsReportResult.cs` | Результат построения ведомости |
| `Services/ElementsReportService.cs` | Единственное место, работающее с документом Revit |
| `ViewModels/MainWindowVm.cs` | Состояние экрана и команды |
| `Views/Style/ElementsReportStyle.xaml` | Палитра, типографика и стили контролов |

Направление зависимостей одностороннее: `MainWindow` знает только про `MainWindowVm`, модель представления только про `IElementsReportService`, реализация сервиса единственная видит `Autodesk.Revit`. Пользовательские строки берутся из `Lang/`, цвета и размеры из файла стилей.

## Строки интерфейса

Ни одной видимой пользователю надписи в коде и разметке нет, все они лежат в `Lang/`. Новая строка заводится сразу в трёх файлах ресурсов: `ElementsReport.resx` и `ElementsReport.ru.resx` с русским текстом, `ElementsReport.en.resx` с английским. После этого в `Lang/ElementsReport.cs` добавляется свойство:

```csharp
/// <summary>
/// Заголовок колонки с уровнем.
/// </summary>
public static string LevelColumn => GetString(nameof(LevelColumn));
```

В разметке строка подставляется как `{x:Static lang:ElementsReport.LevelColumn}`.

## Стили

Файл `Views/Style/ElementsReportStyle.xaml` подключён к окну и содержит палитру, типографику и стили контролов. Свои цвета и размеры шрифта в разметке не пишутся, только ссылки на ключи.

| Ключ | Для чего |
|---|---|
| `Heading1`, `Body`, `Caption`, `DangerText` | `TextBlock` |
| `ReportGrid` | `DataGrid` |
| `Dropdown` | `ComboBox` |
| `TextInput` | `TextBox` |
| `PrimaryButton` | `Button` |
